Electiva - PWA · UPTC (Sub-bloque B)

Qué es esto
-----------
El Atlas 3D con REALIDAD AUMENTADA COMPLETA: el anillo verde (retícula) busca una
superficie con hit-test, tocas para apoyar el cubo, el objeto queda anclado y lo
mueves, giras y escalas con los dedos. Si el dispositivo no ofrece hit-test o
anclas, la app usa un plan B en vez de fallar.
Es el cierre del bloque de WebXR (Sesión 39).

Novedades de la Sesión 39
--------------------------
  src/xr.ts        pide «hit-test» y «anchors» como funciones OPCIONALES;
                   capacidadesDe(sesion) dice cuáles concedió el navegador
  src/visor.ts     retícula, XRHitTestSource con el espacio «viewer», colocar en
                   «select», XRAnchor (y plan B), mover con rayo + plano
  src/gestos.ts    Pointer Events: un dedo mueve, dos dedos giran y escalan
  src/main.ts      texto de ayuda por fase, línea de datos, beforexrselect
  index.html       línea #xr-datos en el overlay
  src/style.css    touch-action: none en el overlay

Cómo probarlo
--------------
  npm install
  npm run build        (compila src/sw.ts y la app)
  npm run preview      → http://localhost:4173

  Hit-test y anclas necesitan un dispositivo AR. En el escritorio, el emulador
  (Immersive Web Emulator) los ofrece pero DOM overlay no: sin overlay no llegan
  los gestos con los dedos. Para verlo completo, usa un teléfono Android con
  ARCore y Chrome, sirviendo la app por HTTPS (GitHub Pages: ver abajo).

Verlo en un teléfono (GitHub Pages)
------------------------------------
  El proyecto ya es compatible con subrutas (usuario.github.io/nombre-repo/):
  nada usa rutas absolutas; todo cuelga de import.meta.env.BASE_URL.
  1. Crea un repositorio público y sube el proyecto (con .github/workflows).
  2. Settings → Pages → Source: GitHub Actions.
  3. Haz push a main: el flujo .github/workflows/pages.yml compila con
     `npm run build -- --base=/nombre-del-repo/` y publica dist.
  4. Abre https://usuario.github.io/nombre-del-repo/ en Chrome del teléfono.

Limitaciones
------------
  - No funciona en iPhone: Safari no ofrece WebXR immersive-ar.
  - Los gestos usan el overlay DOM: sin esa función solo queda «tocar para colocar».
  - Un emulador comprueba el código, no sustituye a un teléfono con ARCore.
  - El cubo es de prueba; el catálogo real de modelos 3D llega más adelante.
